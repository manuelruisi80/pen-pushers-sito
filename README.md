Questo repository è la cartella `/insights/` del sito pen-pushers.com.

- **main** = online. Hostinger lo pubblica da solo a ogni aggiornamento.

Per approvare: apri https://github.com/manuelruisi80/pen-pushers-sito/compare/main...bozze
→ **Create pull request** → **Merge pull request**. Dopo circa un minuto gli articoli sono online.

La redazione automatica segue `_src/ISTRUZIONI.md` e pesca i temi da `_src/argomenti.md`.
